Muninn is unversioned pre-alpha software; keep changes minimal. Without `MUNINN_OWNER_PASSWORD` it has no authentication and is a trusted-network tool; changes to owner auth must not change behavior when the password is unset. Setting the password turns on single-owner login (see `docs/decisions/0001-opt-in-owner-auth.md`); treat `src/auth/` and `src/secrets/` (one-time secrets, see `docs/decisions/0008-one-time-secrets.md`) as security code. Record decisions that are hard to reverse in `docs/decisions/`. Muninn has two entry points in one package: `src/server.ts` for Node and `src/worker.ts` for Cloudflare Workers (see `docs/decisions/0009-cloudflare-workers-profile.md`). Code that the Worker reaches may import only what workerd provides under `nodejs_compat`; `pnpm worker:check` builds the Worker bundle and fails when it reaches a Node-only module. Before submitting, run `pnpm fmt`, `pnpm lint`, `pnpm test`, `pnpm build`, and `pnpm worker:check`; Docker changes also require `pnpm docker:check` and an image build.

Artifacts is unversioned pre-alpha software; keep changes minimal. Without `ARTIFACTS_OWNER_PASSWORD` it has no authentication and is a trusted-network tool; changes to owner auth must not change behavior when the password is unset. Setting the password turns on single-owner login (see `docs/decisions/0001-opt-in-owner-auth.md`); treat `src/auth/` as security code. Record decisions that are hard to reverse in `docs/decisions/`. Before submitting, run `pnpm fmt`, `pnpm lint`, `pnpm test`, and `pnpm build`; Docker changes also require `pnpm docker:check` and an image build.
